# Roadmap and gates

1. **Today:** complete V250 classification, interactive map, gap resolution, details and accounting; run regressions and obtain focused device acceptance.
2. **Track:** preserve Concept A; verify live controls, month/week/day history, pauses, manual entry, Focus and distractions. Correct defects without a visual redesign.
3. **Plan:** the user supplied five visual references and directed implementation to proceed, starting with shared components and Overview. Implement and visually/functionally verify each subsection before beginning the next; keep Today acceptance and native limitations visible.
4. **Goals:** establish and approve a visual concept; implement measurable goals, habits and evidence-based progress.
5. **Insights:** approve visual and analytical concepts; connect reliable time, pattern and plan-versus-reality analysis.
6. **My Life:** approve the Overview / Improve / History concept and integrate relevant personal development features.
7. **Cross-section integration:** review classification, time accounting, planning, goal evidence, sync and recovery across real supported paths.
8. **Android consolidation:** measure system bars and keyboard on target devices, verify notifications/background/offline behavior, then prepare one controlled permanently signed Preview APK when warranted.
9. **Stable release:** complete regression, migration, recovery and security review; obtain explicit approval before production promotion.

A subsection advances only after its required visual approval and focused acceptance, or after the user explicitly agrees to a documented limitation.
