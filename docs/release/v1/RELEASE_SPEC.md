# LifeOS Personal V1.0 — release target

## Authority and scope
This is a design and implementation handover, not a certified release. Existing working behavior and user records are protected. Use the primary individual screens and original references first, release boards second, alternative boards only for supporting ideas. All example values are illustrative. Preserve the six main navigation destinations Today, Track, Plan, Goals, Insights, My Life. Plan retains Overview / Calendar / Tasks / Compare / Improve; Goals retains Overview / Improve / History; Insights retains Live / History / Review. Other board labels are drill-downs, not new mandatory tabs. My Life uses a hub with explicit Fitness, Nutrition, Habits, Routines, Life Areas, Friends & Challenges, and Settings; journal/reflection are optional supporting ideas, not substitutes for existing modules. Do not invent scores or remove existing features to match a mockup.

## Shared design and behavior
Use dark navy surfaces, mint primary actions, muted blue secondary information, semantic amber/red warnings, category colors, consistent outline icons and compact typography. Accessible light theme; readable contrast, no clipped labels or horizontal overflow except intentional calendar scrolling. Use progressive disclosure and meaningful empty states. Keep navigation at the actual safe bottom edge, never over buttons or content; handle system insets, keyboard and reduced height. Touch targets at least 44 CSS px where practical. Use reusable detail sheets and consistent back behavior. Every visible action must work or be explicitly unavailable with reason. Never use browser prompt for core forms. Use real data, explicit unknown states and honest evidence thresholds. Do not fabricate progress, predictions, health metrics or social activity.

## 01 Today
Overview: current date/time, remaining day, live activity and controls, day accounting, four day parts, next commitments/tasks, concise actionable intelligence. Timeline: 24-hour overview with 6-hour zoom and Now; actual/planned lanes aligned to true time, separate overlap lanes only where needed, full width for isolated blocks where feasible, category legend, now marker, gap blocks and readable labels; tiny events remain selectable through accessible list. Tap recorded/planned/live/gap block to open relevant detail/actions. Show start/end, duration, category, notes and overlap context; edit or view source record. Gap logging opens existing manual-entry workflow prefilled with bounds; allow full or partial interval, validate against fresh gap and current time, recalculate remaining unknown immediately; show preceding/following activities. Agenda: upcoming and earlier commitments, tasks, unscheduled windows (not guaranteed free time), confirmation and start actions. Review: elapsed coverage, unknown intervals, concurrent sessions, evidence-based next steps; suppress sub-minute overlap warnings without deleting records. Category breakdown and recorded list expandable, correct show/hide labels, classification correction and averages. Keep prayer/fitness detail accessible without cluttering overview.

## 02 Track
Live tracking: visible active/paused timers, quick start and custom activity, start alongside or switch, pause/resume/finish/edit/delete with safe confirmation; persistent notification and accurate elapsed time when screen locked or app backgrounded. Focus: study/gym entry, countdown, pause/break/resume/finish, sound/vibration and DND controls subject to Android permissions, clear status and no lost session. Manual logging: name/category, start/end, notes, validation, save confirmation and View in History; no duplicate submission. History: month → week → day grouping, expandable days, weekly/monthly/custom filters, summary chart, search and activity detail. Overnight sessions split for reporting, preserve original identity and segment history; show meaningful pause/resume intervals, ignore rapid toggles under a minute in presentation only. Activity detail/edit: original times, segments, duration, category, notes, source and overlap; corrections recalculate all dependent screens. Distractions: classify, edit, delete; no irreversible silent changes. Recognize synonyms and allow manual override (lecture/assignment/course → university; named prayer mapping); never guess unknown test records. Keep recovery/export/import compatible and protect existing data.

## 03 Plan
Overview: retain commitments/tasks cards, workload chart, conflicts, deadlines, weekly summary; compact empty states, labeled bars and correct denominators. Calendar: Day / 3-day / Week / Month, date navigation and Today, actual/planned distinction, category colors, overlapping events and readable short blocks; full week overview with optional horizontal zoom/scroll, sticky time/day headings, current-time line, tap details, add/edit/reschedule. No forced word wrapping such as Te/st or Commitments split. Tasks: weekly selector, progress, collapsible overdue/today/upcoming/completed groups, priority, due date, optional time/duration, check/uncheck, add/edit/delete in integrated styled sheets; retain existing full controls without duplicate legacy UI. Compare: Reality / Planned / Predicted / Ideal, 7/14/30 days, labeled daily axes, totals and averages, category bars and overall progress; no prediction until evidence rules satisfied, no ideal until configured; distinguish unique totals and summed category time. Improve: unverified commitments, unusual durations, conflicts, recommendations with evidence, review/approve, reschedule/carry forward/adjust/skip/partially complete; no automatic changes without approval. Planning tools and recurring blocks accessible without duplicating My Life routines. Latest device screenshots are baseline evidence, not targets: floating navigation, clipped labels, legacy task editor, missing chart axis labels and oversized empty cards remain issues.

## 04 Goals / 05 Insights / 06 My Life
The included Prior_remaining_sections_spec.md supplies detailed functional requirements for these three sections, except its My Life hub is expanded as above. Goals: measurable units, recurrence, milestones, evidence, manual quantity, history and two-week reviews. Insights: live/history/review, activity and day details, trends, distractions and reliability; no invented productivity scores. My Life: retain all fitness, nutrition, body measurements, water, habits and social features in prior spec. Add dedicated routines (today checklist, schedule, templates, prayer/Quran, sleep/recovery), life areas (overview, activities, targets, manage/create), quick actions and connected summaries. Sleep/health data only when actually recorded or connected; no inferred heart rate. Settings include account, theme, reminders, data backup/recovery, privacy and advanced import/export. Social sharing requires authenticated backend and consent; otherwise explicitly local-only. Journal/reflection optional after core release scope.

## Data contracts
Use one canonical interval engine: summed recorded duration = sum of valid active segments; unique time = union of segments; additional overlap = summed minus unique. Clip to local day boundaries (including DST); elapsed = unique + unlogged; full day = elapsed + remaining. Round only for display. Planned time uses union where labeled unique; task completion is not tracked time. Preserve manual versus automatic evidence, stable IDs and historical targets. Avoid double counting across imports, retries, goal matching or synced devices. Predictions and recommendations must explain data sufficiency and uncertainty.
