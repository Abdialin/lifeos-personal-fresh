# Authenticated local replica: V1 visual review

These 393 × 780 CSS-pixel screenshots were captured with `tests/authenticated-isolated-v1.cjs` on 27 November 2026. The test launches this checkout's actual Python server with randomly generated credentials, its own temporary SQLite database and synthetic sessions, plans, tasks, goals, a workout, a meal, a habit and a routine log. It signs in through the app, writes the fixture to that server, verifies both temporary recovery downloads, and restores the fixture through the guarded new-device workflow. No personal account or live Preview database is used. The test shuts down the server and removes its temporary database and downloads.

The localhost replica does not exercise Preview-hostname-only code and is not an authenticated test of the Render deployment. Captures show the browser viewport, not Android system bars or keyboard behavior. A screenshot and a working navigation tab do not establish that a subsection is release-ready. Values are fixture data; differences from illustrative reference values are intentional.
